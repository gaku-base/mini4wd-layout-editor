Mini 4WD Course Layout — Release Candidate v1.0.0-RC1
====================================================

概要
----
3Dを使わない、ローカル完結型のミニ四駆2Dコースレイアウト試作アプリです。
パーツの寸法・接続点・回転中心と、画面に表示する画像を分離しています。

起動方法
--------
1. ZIPを展開
2. run_local.bat をダブルクリック
3. ローカルHTTPサーバーが起動し、既定のブラウザでアプリが開きます

Python 3が必要です。index.htmlの直接オープン（file://）はサポートしません。
run_local_server.bat を直接実行しても同じHTTPサーバーを起動できます。

v0.8.0の主な変更
-----------------
・パーツ定義を part-catalog.js へ分離
・表示画像と、寸法／接続／回転／干渉判定を分離
・Canvaで作成した透明PNGをassets/partsへ置くだけで表示を差し替え可能
・画像がない場合はアプリ内のベクター描画へ自動フォールバック
・参照エディターの1px＝1cm基準から読み取れるパーツ画像枠へ寸法を更新
・3レーン外形幅を36cmとして表示形状を調整
・45度コーナーを中心半径54cm、内半径36cm、外半径72cmへ修正
・コーナーは扇形の面積重心を中心に回転
・ウェーブ、LCジャンプ、バーニングLCも表示重心を回転基準に設定
・20度バンクを28×36cmの入口／出口アプローチとして扱う
・通常区間から7を置くと入口、20度区間から7を置くと出口へ自動切替
・入口と出口の間に置いた通常パーツへbankAngle:20を自動継承
・出口後はbankAngle:0へ戻る
・右下のASSET表示で読み込めたCanva画像数を確認可能

パーツ画像の差し替え
--------------------
詳しいファイル名と画像サイズは次を確認してください。

・CANVA_ASSET_GUIDE.txt
・assets/parts/README.txt

指定された透明PNGをassets/partsへ保存して再起動すると、自動的に画像表示へ切り替わります。
寸法・接続点・回転中心はpart-catalog.jsで管理されるため、画像を差し替えても配置ロジックは変わりません。

Canva用テンプレート
-------------------
assets/templatesに、現在のベクター形状をSVGで収録しています。
Canvaへ読み込み、外観作成時の位置合わせ用テンプレートとして利用できます。

左側パーツ一覧
----------------
1. ストレート
2. コーナー（45度）
3. レーンチェンジ
4. ウェーブ
5. スタート
6. スロープ
7. 20度バンク入口／出口
8. LCジャンプ
9. バーニングレーンチェンジ

20度バンクの作成
----------------
1. 通常区間で7を選択して入口アプローチを配置
2. コーナーやストレート等を1個ずつ配置
3. 中間パーツには20度バンク属性が自動的に付く
4. 再び7を選択すると出口アプローチとして配置
5. 出口以降は通常の0度状態へ戻る

入口＋45度コーナー4枚＋出口の一括プリセットはありません。
各パーツを1個ずつ配置します。

基本操作
--------
・数字1〜9：配置パーツ選択
・クリック：ゴーストパーツを配置
・Z／X／マウスホイール：左／右へ45度回転
・R：最後に配置したパーツを1個削除
・Q：パーツ移動
・W：パーツ削除
・E：カラー変更
・Ctrl＋Z：アンドゥ（最大20工程）
・Ctrl＋Y：リドゥ（最大20工程）
・F：レイアウト全体を手動移動
・Shift＋F：レイアウト外形左上を作成範囲左上へ自動整列
・Ctrl＋ホイール：画面拡大／縮小

注意
----
特殊パーツの高さ、下面空間、支持台、立体交差干渉範囲は今後の実測値で更新します。
参照サイトの画像ファイルはアプリに収録していません。


v0.8.1: ユーザー提供のパーツ画像（assets/parts/*.png）を同梱。20度バンクは bank20-entry.png / bank20-exit.png を役割に応じて切替表示。


v0.8.2: 提供画像の白背景を透明化し、各パーツ画像の縦横比を配置寸法に合わせて再調整。吸着時に画像同士がつながりやすいよう、アセットをトリミング＋比率補正。


v0.8.3 — 画像位置合わせ修正
- 背景だけを透明化し、コース路面の白色は保持
- 画像の外接矩形ではなく接続面を基準に登録
- 45度コーナーは入口面・出口面・外側端の3点でアフィン補正
- ストレートとコーナーのレーン境界が吸着位置で連続
- assets/parts/asset-registration.json を追加


v0.8.4 — 接続表示とレイヤー順
- 45度コーナー同士の接続面に短いレーン継ぎ目補正を描画し、外壁とレーン線を連続表示。
- LCジャンプの接続点を左右中央（±27cm, y=0）へ修正し、画像原点を中央（27cm,18cm）へ変更。
- 配置済みパーツはzIndexで描画。後から配置したパーツが上。
- Q移動で確定したパーツは最前面レイヤーへ移動。複数選択移動も相対順を維持。
- 最前面からヒットテストするため、重なったパーツの選択も描画順と一致。


v0.8.5: コーナー同士の継ぎ目補正を強化。継ぎ目パッチを拡張し、コーナー同士/コーナー接続時の外壁線・レーン線がより連続して見えるよう調整。


v0.8.6: corner45.pngを数式から生成した正確な45度円弧画像へ置換。中心半径54cm、内半径36cm、外半径72cm、レーン境界半径48/60cm。8枚接続時の閉合誤差 0.000000000000cm。コーナー同士の補正パッチは廃止。


v0.8.7: 移動・削除・カラー変更モードのホバー候補を実形状で強調表示。コーナーのクリック判定と範囲選択を外接四角形から45度扇形判定へ変更し、中央の空白や外側の四角領域では選択されないよう修正。


v0.8.8:
- Q移動モードで複数選択したグループの空き接続点を自動検出。
- 配置済みコースの空き接続点へ28cm以内まで近づけると、向きが一致する最短候補へグループ全体を吸着。
- 吸着中は接続点に「接続吸着」エフェクトを表示。
- 移動確定後は従来どおり選択グループを最前面へ移動。


v0.8.9: パーツごとに異なっていたコース面の色を、45度コーナーの色味に統一。bank20-entry / bank20-exit / slope の画像をグレートーン化し、コーナーパーツと近い色味へ調整。


v0.9.0:
- 標準グレー系（スタート、ストレート、45度コーナー、レーンチェンジ、ウェーブ、LCジャンプ、バーニングLC）を同一パレットのベクター描画へ統一。
- 標準色はベース #EFEDE9、レーン線 #8D8C89、外周線 #858480。
- スロープと20度バンクは以前のグリーン画像を標準表示へ復元。
- バーニングLCは画像を使わず透明背景のベクター描画へ変更し、中央・外側の不要な白背景を除去。


============================================================
v1.0.0-RC1 人力QA候補版
============================================================
この版では新機能追加を停止し、既存機能の人力QAを優先します。
同梱の HUMAN_QA_CHECKLIST.csv を上から順に実施し、問題があれば BUG_REPORT_TEMPLATE.txt の形式で記録してください。

RC1対象範囲
- スタート配置と前後からの連続作成
- 9種類のパーツ選択・ゴースト・45度回転・接続吸着
- 単体／複数移動、グループ吸着、最前面レイヤー
- 削除、カラー変更、Undo／Redo、Rでの巻き戻し
- クリック／Shiftクリック／範囲選択／ホバー表示
- JSON保存・読込、PNG出力
- 20度バンク入口・出口とbankAngle状態の継承

RC1対象外
- 高さ・支柱・立体交差の実干渉判定
- 自動レイアウト生成
- 3D表示
