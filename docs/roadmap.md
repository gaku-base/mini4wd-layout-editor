## Phase 1.5：寸法計測マスター・スロープ／バンク衝突プロファイル

Phase 2の干渉エンジンへ進む前に、Issue #6として実施する。

### 計測ルールと記録形式

- `docs/measurement-protocol.md` を作成
- `docs/part-master.md` を拡張
- すべての数値を `verified` / `provisional` / `unknown` で管理
- 測定元、測定日、測定者、基準寸法、視点、計算方法、許容誤差、信頼度を記録
- 3D表示から推定した値は原則 `provisional`
- 公式寸法または実物採寸で確認できた値だけを `verified` へ昇格
- 未確認寸法を推測で確定しない

### NOIR公開3D表示からの綿密な採寸

- 通常の公開画面操作だけを使用
- 上面、側面、正面、背面、斜視など複数方向から同じ部位を確認
- ストレート540mm、スロープ高低差115mmなどの既知寸法で縮尺を校正
- 透視歪みが少ない視点を優先
- 同一寸法を複数視点・複数回で測り、平均値、ばらつき、想定誤差を記録
- 採寸結果は数値、断面点列、独自の簡略形状として保存

### スロープの採寸項目

- 全長、全幅、全高
- 入口・出口のXYZ座標、方向、高さ
- 長手方向の複数断面
- 各断面の走行面高さ
- 各断面の下面高さ
- 内外側壁の上端・下端形状
- 下を通過できる有効高さと有効幅
- 接続部の正常接触除外範囲
- 上り・下り方向で共通利用できるプロファイル仕様

### バンクの採寸項目

- 全長、中心角、内外半径、全幅、全高
- 入口・中央・出口と複数の中間断面
- 進行方向距離または中心角ごとの走行面高さ
- 横断勾配と傾斜変化
- 下面高さと下面形状
- 内外側壁の上端・下端形状
- 下を通過できる有効空間
- 接続部の正常接触除外範囲

### 知的財産・安全上の境界

- NOIRのソースコード、画像、3Dモデル、メッシュ、テクスチャ、ロゴをコピー・保存しない
- 開発者ツール、通信解析、キャッシュ解析などで元3Dファイルを抽出しない
- アクセス制限、認証、暗号化、技術的保護を回避しない
- 自動巡回、大量アクセス、負荷をかける取得を行わない
- 計測用スクリーンショットをリポジトリへ登録・再配布しない
- 規約上または法的に疑わしい方法が必要になった場合は作業を停止する
- 元3D表現をそのまま再現せず、独自の表示形状・衝突判定形状を作成

### Phase 1.5の完成条件

- 3レーンストレート、45度コーナー、スロープ、バンクの記録形式が定義済み
- スロープ下の通過可能・不可能範囲を後続エンジンが判定できる
- バンクの走行面・下面・側壁を後続エンジンが判定できる
- collision profileをバージョン管理して差し替えできる
- 支柱、橋脚、補強材は判定対象外と明記
- 精密3D干渉エンジン自体はまだ実装しない
