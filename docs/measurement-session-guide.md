# 手動採寸セッションガイド

## 1. 目的

本書は、公開3D表示を通常の画面操作で人が観察し、スロープとバンクの計測値を再現可能な形で記録するための実務手順を定める。記録結果は [`measurement-protocol.md`](measurement-protocol.md) のmeasurement recordとcollision profileへ転記する前の作業記録とする。

使用するワークシート：

- [スロープ採寸ワークシート](measurement-worksheets/slope.md)
- [バンク採寸ワークシート](measurement-worksheets/bank.md)

この手順は数値の採用や`verified`への昇格を自動化しない。公開画面から得た値は原則`provisional`であり、確認できない値は`unknown`のまま残す。

## 2. 知的財産・アクセス・安全チェック

セッション開始前に全項目を確認する。

- [ ] 公開画面を通常のUI操作だけで観察する。
- [ ] NOIRのコード、画像、3Dモデル、メッシュ、テクスチャ、ロゴを保存、コピー、再配布しない。
- [ ] 開発者ツール、通信解析、キャッシュ解析等で元3Dファイルを抽出しない。
- [ ] アクセス制限、認証、暗号化、難読化、技術的保護を回避しない。
- [ ] 自動巡回、スクレイピング、大量アクセス、負荷を与える反復取得を行わない。
- [ ] スクリーンショットは一時的な手動計測にだけ使用し、リポジトリへ登録しない。
- [ ] 法令または利用規約に疑義がある手法が必要になった場合は作業を停止し、Issueへ報告する。

チェックできない項目がある場合はセッションを開始しない。

## 3. セッション識別情報

同じ条件で再実施できるよう、ワークシートへ次を記録する。

| 項目 | 記録内容 |
|---|---|
| session ID | 重複しない文字列。未決定なら`unknown` |
| 対象パーツ | スロープまたはバンク、製品版・向きが分かれば併記 |
| 測定日 | `YYYY-MM-DD`。未実施は`unknown` |
| 測定者 | 追跡可能な担当者ID。未実施は`unknown` |
| 数値化・確認担当 | 担当者ID。未決定は`unknown` |
| 公開画面の参照 | ページ名、公開URL、表示バージョンが分かる範囲 |
| ブラウザー・画面条件 | ブラウザー、表示倍率、画面解像度、OS |
| 対象の向き | 入口→出口、上り／下り、左／右。不明は`unknown` |

## 4. 必要な視点

同じ部位を複数方向から確認する。各視点に`view ID`を付け、カメラ操作や表示条件が変わったら新しいIDにする。

| 視点 | 主な確認項目 | 寸法読取時の注意 |
|---|---|---|
| 上面 | 2D外形、中心線、全長、半径、コネクタXY | Z方向寸法は読まない |
| 左側面 | 長手方向の走行面・下面・側壁、コネクタZ | 対象側面を画面へ平行に近づける |
| 右側面 | 左側面の照合、左右非対称 | 左側面の数値をそのまま流用しない |
| 正面 | 入口断面、全幅、走行面、下面、側壁 | 入口接線方向から確認する |
| 背面 | 出口断面、全幅、走行面、下面、側壁 | 出口接線方向から確認する |
| 斜視 | 形状変化点、部位対応、死角 | 原則として単独の寸法確定には使わない |
| station確認視点 | 入口、中央、出口、中間断面 | 対象断面が画面へ正対する条件を記録する |

記録欄には少なくとも、`view ID`、視点種別、カメラ方向、投影方式が分かるか、表示倍率、校正ID、透視歪みの懸念、確認したstationを残す。

## 5. 既知寸法による縮尺校正

利用できる確定済み公称値は次の2つだけである。

- ストレート1枚の長さ：540mm（verified）
- スロープ高低差：115mm（verified）

これ以外の未確認寸法を校正基準として使わない。

### 5.1 校正手順

1. 測定対象と同じ表示倍率、投影条件、可能な限り同じ奥行き位置へ既知寸法を表示する。
2. 既知寸法に対応する画面上の長さを手動で読む。画面上単位は`screen-unit`として記録し、画像や画面そのものをリポジトリへ保存しない。
3. `scaleMmPerScreenUnit = knownLengthMm / observedScreenLength`を計算する。
4. 水平方向と垂直方向で縮尺が異なる可能性があれば別々の校正IDを作る。
5. カメラ、ズーム、ウィンドウサイズ、投影方式が変わったら再校正する。
6. 基準物と対象物の奥行きが大きく異なる場合、その校正を使用せず`unknown`とする。

### 5.2 校正記録

| 項目 | 記録 |
|---|---|
| calibration ID | `unknown` |
| view ID | `unknown` |
| 既知寸法 | 540mmまたは115mm。使用しない場合は`unknown` |
| 画面上の読取長 | `unknown` |
| mm / screen-unit | `unknown` |
| 反復読取回数 | `unknown` |
| 平均 | `unknown` |
| 最大差 | `unknown` |
| 推定誤差 | `unknown` |
| 状態・信頼度 | `unknown` / `none` |
| 備考 | `unknown` |

## 6. 透視歪みを抑える操作と記録

- 対象面または断面を画面へ正対させ、透視歪みが少ない視点を優先する。
- 公開UIに正投影機能が明示されている場合だけ使用し、投影方式と操作を記録する。
- 斜視は部位確認に使い、寸法読取は正対に近い上面・側面・正面・背面で再確認する。
- 画面の手前と奥で同じ寸法が異なって見える場合は、奥行き差を解消するか別校正を行う。
- 左右・前後の対応を複数視点で照合し、隠れた面を見えている面から推測しない。
- アンチエイリアス、線幅、影、透明表示で端点が曖昧な場合は、読取規則と曖昧さを記録する。
- 歪みや基準点を評価できない値は数値化せず`unknown`とする。

## 7. stationの設定

割合は採寸計画上のラベルであり、実寸ではない。対応する`sMm`または`thetaDeg`は校正・計測できるまで`unknown`とする。

### 7.1 スロープ

- 入口
- 25%
- 50%
- 75%
- 出口
- 形状変化点がある場合の追加station

### 7.2 バンク

- 入口
- 25%
- 中央
- 75%
- 出口
- 形状変化点がある場合の追加station

各stationは、走行面、下面、内外側壁、有効高さ、有効幅を同じ断面として関連付ける。形状変化点の追加stationには、追加理由と確認視点を記録する。

## 8. 反復測定と集計

各項目について、セッション計画で決めた複数回の読取を個別に残す。実施回数を記録し、値を上書きしない。

### 8.1 必須記録欄

- 測定項目ID
- station ID
- 使用したview IDとcalibration ID
- 計画回数と実施回数
- 各回の読取値
- 平均値
- 最大差
- 推定誤差と計算方法
- 信頼度
- `verified` / `provisional` / `unknown`
- `unknown`理由

### 8.2 集計方法

数値が得られた回だけを対象にし、除外値がある場合は元の値と除外理由を残す。

- 平均値：`sum(values) / count(values)`
- 最大差：`max(values) - min(values)`
- 反復性による誤差成分：計算方法を明記する。既定案として`maximumDifference / 2`を使用できる
- 推定誤差：校正誤差、透視歪み、端点読取、反復性など、採用した誤差成分と合成方法を明記する

推定誤差の根拠が不足する場合は数値を作らず`unknown`とする。測定回数が平均や最大差の計算に足りない場合も、その集計欄を`unknown`にする。

## 9. 状態と信頼度の判定

公開画面から人が読んだ値は原則`provisional`とする。ワークシートだけで`verified`へ昇格しない。

| 状態・信頼度 | セッションでの扱い |
|---|---|
| `provisional / medium` | 複数視点・複数回が整合し、校正と推定誤差を記録できた |
| `provisional / low` | 数値はあるが単一視点、歪み、基準点、反復性に懸念がある |
| `unknown / none` | 数値がない、または推測しないと値を置けない |

`high`または`verified`は、measurement protocolの基準に従い、一次資料、実物計測、独立確認、明示承認を伴う別レビューで決定する。

## 10. コネクタと正常接触除外範囲

入口・出口ごとに次を確認する。

- 物理基準点として使用した部位
- XYZ座標
- `headingDeg`
- `elevationDeltaMm`
- 接続相手と正常に重なる部位
- 正常接触除外体積の形状種別と境界
- 正式接続時だけ除外できること

基準点や除外境界が見えない場合は推測せず`unknown`とする。接続関係のない食い込みを除外してはならない。

## 11. measurement recordへの転記

ワークシートの各集計値を転記する際は、次を対応付ける。

| ワークシート | measurement record |
|---|---|
| 測定元・ページ | `source.reference` |
| 測定項目・観察メモ | `source.observationNote` |
| view ID一覧 | `observation.viewpoints` |
| calibration ID | `observation.calibrationReference` |
| 集計・誤差計算式 | `observation.calculationMethod` |
| 実施回数 | `observation.repeatCount` |
| 最大差等のばらつき | `observation.dispersion` |
| 測定日・測定者 | `measuredAt` / `measuredBy` |
| 推定誤差 | `tolerance` |
| 信頼度 | `confidence` |
| unknown理由 | `notes` |

転記後も元ワークシートを変更履歴として保持する。collision profileへ採用する場合は別レビューでversion、measurement revision、変更概要を決定する。
