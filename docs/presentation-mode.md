# 発表用レイアウト機能

Issue #90の実装仕様。P1〜P6を段階的に実装し、最終Chromiumリハーサルまで全項目を確認する。

## 背景

完成したコースを編集UIなしの平面図として発表・共有・印刷する。

## 確定仕様

- 大会名は2行入力（1行目必須、2行目任意）
- レイアウター名は任意。空欄ならラベルごと非表示
- 編集時のパーツカラーを保持
- 平面図のみ。3D表示は行わない
- 背景: Grid / White / Transparent
  - Grid = ホワイト背景＋薄いグレーの実寸1mグリッド
  - White = ホワイト背景、グリッドなし
  - Transparent = 透明背景、グリッドなし
- 全延長をmで表示。未定義長は推測せず算出不可
- 使用パーツだけを種類別集計。色別には分けない
- 高解像度PNG出力
- A4縦／横／自動方向、1ページ印刷
- 発表ビューは読み取り専用。編集stateやUndo/Redoを変更しない

## 実装フェーズ

1. P1 発表用データ基盤
2. P2 発表専用2Dレンダラー
3. P3 発表画面UI
4. P4 PNG画像出力
5. P5 A4印刷
6. P6 総合QA・リハーサル
