# 製品仕様書

## 1. 製品概要

2D操作を中心としながら、内部ではmm単位のXYZ座標とパーツ本体の3D形状を保持するミニ四駆コースレイアウトエディター。

主目的は、速く描くことだけではなく、現地で組めないパーツ干渉を作成時点で検出し、部分編集や仮置きを安全に行えること。

## 2. v1.0の主要要件

- 数字キーによるパーツ選択
- マウスポインター追従シャドー
- 直前パーツ出口角度を用いた初期角度
- ホイールおよびZ/Xによる45度回転
- クリック吸着配置
- 単体パーツ編集時の選択外固定
- 連結区間の双方向選択
- 複数連結パーツの切り離し・仮置き
- 未接続端点の可視化
- 接続候補のシャドー表示
- 作成操作へ追従する接続補助
- XYZ高さ管理
- コースパーツ本体同士の3D干渉判定
- 干渉箇所の赤色表示とアラート
- Undo・Redo
- 自動保存、JSON入出力、PNG・SVG出力
- オフラインPWA
- 在庫管理、会場寸法、設営図

## 3. 操作仕様

### 3.1 パーツ配置

1. 数字キーでパーツを選択する。
2. 半透明シャドーをマウスポインターへ表示する。
3. アクティブな接続点の出口方向からシャドーの初期角度を求める。
4. ホイールまたはZ/Xで45度ずつ回転できる。
5. 手動回転後は自動角度へ戻さない。
6. クリックで入口コネクタをアクティブ出口へ吸着させる。
7. 45度コーナーは右／左の曲がり方向とは独立に入口A/Bを毎回比較し、24px以内の最短接続口を自動採用する。入口A/Bを利用者に指定させない。
8. 配置後、新パーツの出口をアクティブ接続点とする。

### 3.2 ホイール操作

- 配置シャドーあり：45度回転
- 単体・グループ選択中：選択対象を45度回転
- Ctrl＋ホイール：画面ズーム
- 対象なし：画面ズーム

### 3.3 部分編集

- 変更したパーツ・選択区間だけを移動する。
- 変更対象外のパーツ座標は固定する。
- 接続切れは未接続端点として残す。
- 元位置の補助表示を可能にする。

### 3.4 区間選択

- 起点パーツと終点パーツを指定する。
- 閉ループ上の2経路を算出する。
- 走行方向側と逆方向側を切り替え可能にする。
- 選択パーツ数と方向を表示する。

### 3.5 仮置き

- 選択区間を独立グループとして切り離す。
- 移動、45度回転、複製、削除、再接続、元位置復帰を行える。
- 複数の仮置きグループを保持できる。
- 仮置き状態を保存できる。

## 4. 高さ・干渉仕様

### 4.1 基本

- 画面は2Dだが内部はXYZ座標を持つ。
- ストレート長は540mm。
- スロープ高低差は115mm。
- 支柱・橋脚・固定具は判定対象外。
- コースパーツ本体同士だけを判定する。

### 4.2 スロープ

スロープは入口高・出口高だけではなく、長手方向ごとの走行面、下面、側壁を表現できる3D衝突形状を持つ。

同じ下側コースでも、スロープ入口寄りでは干渉し、出口寄りでは通過可能となる差を判定する。

### 4.3 干渉表示

- 正常な立体交差：通常表示
- 余裕が小さい状態：オレンジ警告
- 明確な干渉：両パーツを赤枠、干渉範囲を半透明赤、交差位置に×印
- エラー一覧から対象箇所へ移動できること

## 5. 接続補助

- 2つの未接続端点を結ぶパーツ構成を探索する。
- 候補は実パーツとは別レイヤーの半透明シャドーで表示する。
- 候補の一部を手動配置した場合は、残りだけを再提示する。
- 異なるパーツを配置した場合は、現在状態から再探索する。
- 候補を勝手に実パーツ化しない。

## 6. 初期開発スコープ

第1段階では以下に限定する。

- React＋TypeScript＋Viteの基盤
- Vitestによる単体テスト
- mm単位XYZ型
- 入口・出口コネクタ型
- 45度単位の座標回転
- ストレート540mm
- スロープ高低差115mm
- 未確認寸法を状態付きで管理する仕組み
- 接続計算と高さ継承のテスト

完成UI、精密3D衝突モデル、在庫、会場、PWAはこの段階では実装しない。
