# パーツ寸法マスター

## 状態の定義

- `verified`：確定値。根拠が明確で実装に使用してよい。
- `provisional`：暫定値。構造検証には使えるが正式判定へ使用しない。
- `unknown`：未確認。推測で埋めない。

## 3D形状計測方針

NOIR Course Layout Makerの3D表示を寸法・形状把握の参考にする。ただし、コード、画像、3Dモデル、素材はコピーしない。

各パーツについて最低限、以下を計測・定義する。

1. 全長・全幅・全高
2. 入口・出口コネクタ位置
3. 入口・出口方向
4. 入口・出口高さ
5. 2D投影外形
6. 走行面形状
7. 下面形状
8. 側壁形状
9. 接続部の正常接触領域
10. 独自の簡略3D衝突形状
