# スロープ2枚による二段交差の幾何確認

調査日: 2026-09-02

## 前提

正式採用済みの1枚スロープ:

- 水平投影: 540mm
- 高低差: 115mm
- 低端側の床まで塞ぐ側壁区間: 270mm
- 干渉判定用安全マージン: 2mm
- 下段通過NG境界: X<=272mm
- 下段通過OK領域: X>272mm
- 長手基準曲線: R398mm → 169.1005617968mm直線 → R803mm

2枚を高端同士で接続すると、判定上の安全開口は高端側268mm + 268mm = 536mmになる。

## 中央90degree交差はQA例

現行アプリのJCJC接続面外幅370mmを中央に90degree交差させる例では:

- 安全開口長: 536mm
- 下段コース参照外幅: 370mm
- 左右安全余裕: `(536 - 370) / 2 = 83mm`
- 最も低い側の評価station: X=355mm
- X=355mmの走行面高さ: Z=93.3987458398mm

この例は回帰テスト・説明用に保持するが、本番の通過判定の正本ではない。

## 本番判定

実際の下段コースは中央だけでなく、低端寄り、高端寄り、斜めなど任意位置を通る。

本番では下段コースの平面占有polygonをスロープローカルX軸へ投影し、スロープと重なるX範囲で判定する。

- 重複範囲にX<=272mmが1点でも含まれる: NG
- 重複範囲全体がX>272mm: OK
- 平面上で重ならない: 判定対象外

したがってX=355mmを固定のクリアランス基準点として扱わない。

## 参考計算

通常JCJCストレートの外側総高さ57mm、スロープ走行面から下面まで2mmという仮定を置く場合、中央90degree例のX=355mmでは:

- 候補下面高さ: `93.3987458398 - 2 = 91.3987458398mm`
- 候補垂直余裕: `91.3987458398 - 57 = 34.3987458398mm`

これは形状QAの参考値であり、通過可否の正本ではない。

## 実装

- `classifyUnderpassLongitudinalRange()` を正式な長手方向判定helperとする。
- `centeredTwoSlopeCrossoverReference()` は中央90degree交差のQA helperに限定する。
- 次段階でcollision側から、回転を含む下段コースpolygonの投影範囲を渡す。

## 次の回帰ケース

- 低端寄りでX=272mmへ触れる配置: NG
- X=272mmをわずかに超えて全体が高端側へ収まる配置: OK
- 高端寄り配置: OK
- 斜め配置で角だけX<=272mmへ入る: NG
- 同じ斜め角でも全体がX>272mm: OK
