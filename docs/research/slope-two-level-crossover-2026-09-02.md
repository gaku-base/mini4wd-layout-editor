# スロープ2枚による二段交差の幾何確認

調査日: 2026-09-02

## 前提

正式採用済みの1枚スロープ:

- 水平投影: 540mm
- 高低差: 115mm
- 低端側の床まで塞ぐ側壁区間: 270mm
- 高端側の開口候補区間: 270mm
- 長手基準曲線: R398mm → 169.1005617968mm直線 → R803mm

2枚を高端同士で接続すると、高端側270mm + 270mmにより、長手方向の連続開口候補は540mmになる。

タミヤ純正説明書にも、2枚のスロープを使った二段交差の使用例が描かれている。

## 下段コースを中央に90degree交差させる場合

現行アプリで安全側に使用しているJCJC接続面外幅370mmを、下段コースの保守的な外幅参照として使う。

- 連続開口候補長: 540mm
- 下段コース参照外幅: 370mm
- 左右余裕: `(540 - 370) / 2 = 85mm`

したがって、中央配置した下段コースの外縁は各スロープの高端から185mm入り込む。
低端をX=0、高端をX=540とすると、最も低い側の評価stationは:

`X = 540 - 370/2 = 355mm`

正式長手曲線によるX=355mmの走行面高さは:

`Z = 93.3987458398mm`

X=270mmの走行面高さ68.4398289257mmより約24.96mm高い。

## provisionalな垂直余裕の参考計算

通常JCJCストレートの外側総高さを57mm、スロープ走行面から下面までのオフセットを仮に2mmと置くと:

- X=355mmの候補下面高さ: `93.3987458398 - 2 = 91.3987458398mm`
- 下段コースとの候補垂直余裕: `91.3987458398 - 57 = 34.3987458398mm`

ただし57mmと2mmはスロープのcollision確定値ではない。特に2mmはストレート実測系資料からのprovisional転用である。

## 実物裏面写真で確認できた事項

中古出品の実物写真から、スロープ裏面は単純な一定厚の平板ではないことを確認した。

- 高端接続部に複数の係合ツメがある
- 裏面に円形ボスがある
- 補強リブ／ガセット状の下向き突出部がある
- 高端接続付近には走行面下面より下へ突出する構造が存在する

参照:
- https://auctions.yahoo.co.jp/jp/auction/1201609162

このため、路面板厚だけから最終通過高さを決めない。
`centeredTwoSlopeCrossoverReference()` は水平収まりと評価stationを確定し、下面オフセットと下段高さが明示された場合でも結果をcandidateとして扱う。

## 別系統の実物トレース資料

Mini4Scienceは実物スロープをmm単位でマッピングし、次を報告している。

- base length: 54cm
- slope height: 11.85cm
- slope incline angle: 15degree
- 上り側と高端側は非対称

参照:
- https://www.mini4science.com/2025/05/slope-jump-section-mapped/

これは現在のプロジェクト正式値（115mm、R398→直線→R803から導出した18.4237degree）とは一致しない。
プロジェクト所有者が正式モデルを明示承認済みのため、この外部実測値で自動上書きはしない。今後、実物採寸または一次資料で再検証するときのQA比較データとして保持する。

## 現時点の判定

### verified / derived verified

- 2枚高端接続時の開口候補長: 540mm
- 370mm幅を中央配置した場合の左右余裕: 85mm
- 評価station: X=355mm
- その走行面高さ: 93.3987458398mm

### provisional

- 下段コース外側総高さ: 約57mm
- スロープ走行面→下面オフセット: 2mm仮参照
- 上記仮定時のX=355mm候補垂直余裕: 約34.40mm

### unknown

- 高端接続ツメの最下面高さ
- 補強リブ／ガセットの最大突出量とX/Y位置
- 円形ボスの突出量
- 下段コースが実際に通過するY方向全幅に対する最小クリアランス
- 実物スロープの走行面→下面オフセット

これらが揃うまでは3D collision profileをactiveにしない。
