# スロープ下通過判定 272mm安全境界

決定日: 2026-09-02
状態: verified（project-owner decision）

## 決定

物理的に床まで塞ぐ側壁は低端から270mmまでとする既存決定を維持する。

レイアウト干渉判定では2mmの安全余裕を加え、低端からX=272mmまでは下段コース通過NGとする。

- 物理側壁終端: X=270mm
- 安全マージン: 2mm
- 干渉判定NG: X<=272mm
- 通過OK: X>272mm
- X=272mmちょうどはNG

2mmは側壁寸法そのものへ加算せず、干渉判定用の独立した安全マージンとして管理する。

## 任意配置への適用

下段コースの交差位置・角度は固定しない。

下段コースの平面占有形状をスロープローカル座標へ変換し、スロープと重なる部分を長手X軸へ投影する。

- 投影重複範囲の最小X<=272mm: NG
- 投影重複範囲の最小X>272mm: OK

これにより中央90degree、低端寄り、高端寄り、斜め交差を同じ基準で判定する。

## 2枚高端接続時

各スロープの判定上の安全開口は `540-272=268mm`。

高端同士で2枚接続した場合の連続安全開口は:

`268 + 268 = 536mm`

従来の270mm物理開口だけから計算した540mmは物理参考値として残るが、干渉判定では536mmを使用する。

## 中央交差について

X=355mmなど中央90degree交差から導いた値はQA例としてのみ保持する。本番判定の固定基準点にはしない。
