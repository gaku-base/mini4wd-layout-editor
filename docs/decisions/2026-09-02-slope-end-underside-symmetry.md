# スロープ端部下面形状の共通化

決定日: 2026-09-02
状態: verified（project-owner decision）

## 決定

スロープの高端側にある接続ツメ・補強リブ・ガセット等の下面突出条件は、低端側と同じ条件として扱う。

- 高端側だけの追加突出量パラメータは設けない。
- 低端側と高端側で別々の下面突出寸法を持たせない。
- 共通の「走行面から下面／最大突出部までのオフセット」を1つ確定できれば、両端へ同じ値を適用する。
- R398→直線→R803の長手走行面形状そのものを左右対称とする決定ではない。R398とR803の既存正式モデルはそのまま維持する。
- 270mmの床まで塞ぐ側壁区間も既存定義を維持する。

## 二段交差への適用

2枚のスロープを高端同士で接続する二段交差では、高端側固有の追加リブ補正を加えない。

ただし、共通の走行面→下面／最大突出部オフセット値そのものはまだ未確定なので、その数値が決まるまでは最終的な垂直collision clearanceをverifiedへ昇格しない。

## 次に必要な値

- 低端側を代表断面とした、走行面から下面または最下突出部までの最大深さ(mm)

この1値を両端へ共通適用する。
