# スロープ側壁・長手形状（270mm / 50mm / 2.5mm / R398→直線→R803）

決定日: 2026-09-01
状態: verified

## 側壁寸法

- 3レーンスロープの左右側壁は、低い側から270mmの区間を「床まで塞ぐ側壁」として採用する。
- 側壁の走行面から上の高さは50mmとする。
- 側壁の板厚は2.5mmとする。
- 270mmと2.5mmはプロジェクト所有者の明示承認によりverifiedとする。2.5mmは参考設計資料の材料厚表記とも一致する。
- 50mmはタミヤ公式のコースフェンス高さ5cmと、スロープ設計資料の50mm表記が一致しているためverifiedとする。

## 長手方向の正式形状

プロジェクト所有者の明示承認により、低い側から高い側へ次の接線連続形状を正式採用する。

1. R398mm円弧
2. 傾斜直線
3. R803mm円弧

既存の水平投影540mm・高低差115mmを同時に満たし、両端を水平、円弧と直線を接線連続にすると、未知量は一意に次の値となる。

- R398円弧半径: 398mm verified
- 中間直線の実長: 169.1005617968mm verified
- 中間直線の傾斜角: 18.4237410094degree verified
- R803円弧半径: 803mm verified
- 水平投影: 540mm verified
- 高低差: 115mm verified

270mmは中間直線長ではない。270mmは床まで塞ぐ側壁の水平区間を示す独立寸法として保持する。

## 接続点

低端をX=0mm、Z=0mm、高端をX=540mm、Z=115mmとする。

- R398終了／直線開始:
  - X=125.7847896090mm
  - Z=20.3994349805mm
  - 接線角=18.4237410094degree
- 直線終了／R803開始:
  - X=286.2181254874mm
  - Z=73.8423460066mm
  - 接線角=18.4237410094degree
- 高端:
  - X=540mm
  - Z=115mm
  - 接線角=0degree

このためR398→直線→R803は位置と接線の両方でシームレスにつながる。

## 実装方針

- 正式な長手形状は `slope-longitudinal-profile.js` を正本とする。
- `slope-longitudinal-profile.test.js` で540mm・115mm閉合、両接続点の高さ連続、接線連続、270mmとの独立性を検証する。
- この決定で走行面／長手基準曲線は確定するが、下面・床まで塞ぐ側壁の270mm終端断面・高い側の開口断面がまだ不足するため、完全な3D collision profileはまだactiveにしない。
- 保存形式、既存配置データ、現在のUI警告動作は変更しない。
