# スロープ側壁寸法（270mm / 50mm / 2.5mm）

決定日: 2026-09-01
状態: verified

- 3レーンスロープの左右側壁は、低い側から270mmの区間を「床まで塞ぐ側壁」として採用する。
- 側壁の走行面から上の高さは50mmとする。
- 側壁の板厚は2.5mmとする。
- 270mmと2.5mmはプロジェクト所有者の明示承認によりverifiedとする。
- 50mmはタミヤ公式のコースフェンス高さ5cmと、スロープ設計資料の50mm表記が一致しているためverifiedとする。
- 参考設計資料の組立図では、側壁上側の曲線付近にR398mm、270mm以降の開口下面側の曲線付近にR803mmが示されている。この対応は形状復元の有力根拠だが、円弧の開始・終了点と接線条件が図面上で数値定義されていないため、現段階ではprovisionalとする。
- 既存の540mm水平接続距離モデルと115mm高低差モデルは変更しない。
- R398/R803の半径だけから円弧中心やstation高さを一意に推測せず、完全な3D collision profileを生成しない。
- 保存形式、UI、既存配置データ、現在の警告動作は変更しない。

現在のverified寸法:

- 床まで塞ぐ側壁長（低い側から）: 270mm
- 側壁高さ（走行面から上）: 50mm
- 側壁厚: 2.5mm
- スロープ高低差: 115mm
- エディター既存の水平接続距離: 540mm

参考図面からのprovisional形状情報:

- 側壁上側曲線付近: R398mm
- 高い側の開口下面曲線付近: R803mm
- 270mm位置: 床まで塞ぐ区間の終端

次に必要な確定作業:

- R398mm / R803mm各円弧の開始・終了点と接線条件の特定
- 270mm終端の段差位置と下面曲線の接続条件
- 走行面の長手方向高さプロファイル
- 高い側の開口形状
- 下段コースの通過可能な有効高さ・有効幅
- station単位のcollision profile化
