# スロープ側壁の床塞ぎ区間270mm

決定日: 2026-09-01
状態: verified

- 3レーンスロープの左右側壁は、低い側から270mmの区間を「床まで塞ぐ側壁」として採用する。
- 根拠はプロジェクト所有者の明示承認。
- この270mmから、側壁全体長、高い側の開口長、壁高、壁厚、下面曲線を自動的に確定しない。
- 未確認部分はunknownのまま保持し、270mmだけから完全な3D collision profileを生成しない。
- 既存の540mm水平接続距離モデルと115mm高低差モデルは変更しない。
- 保存形式、UI、既存配置データ、現在の警告動作は変更しない。

次に必要な採寸:

- 側壁の壁高
- 側壁の壁厚
- 270mm終端付近の断面形状
- 高い側の開口形状
- 下面プロファイル
- 下段コースの通過可能な有効高さ・有効幅
