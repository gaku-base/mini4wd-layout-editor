# 実測更新: Bank20 220mm / スロープ床接地 290mm

- Date: 2026-09-27
- Status: verified / project-owner real measurement

## 採用値

### 20度バンク

- 実測したパーツ長: `220mm`
- 配置・接続の connector span: `220mm`
- editor internal XY unit: `22cm`
- local connector X: `-110mm / +110mm`
- 3レーン総延長表示: 従来どおり `0.66m`（1レーン換算22cm）

従来の230mm connector spanは、本実測によりsupersededとする。

### スロープ

- スロープ全体の水平接続間: `540mm` を維持
- 高低差: `115mm` を維持
- 低い側から床まで塞ぐ／床と接する側壁長: `290mm`

290mmはスロープ全長ではない。全体の接続間540mmとは独立した床接地・干渉判定用寸法として扱う。

既存の干渉判定安全マージン2mmを維持するため、

- 物理床接地終端: `290mm`
- 安全マージン: `2mm`
- 下通過NG境界: `X <= 292mm`
- 下通過可能: `X > 292mm`

とする。
